# Sunlit Spin Polisher

https://www.eve-rotary.com/en/
https://www.sun-dental.de/product-lists-en/tcp543204m



بمین. اه، این، اه، پرونده که بهت دادم برای این قالبیه که میخوام برای چیزی که میخوام برام بسازی استفاده کنی. اه، اون دوتا لینکی که بهت دادم اولی ایو، اه، وبسایت رقیبمونه. دومی اون پروداکتیه که میخوایم توی این، اه، وبسایت بفروشیم. اون پروداکتهایی که برات فرست-- کلا همین یه دار پروداکت هستش. میخوام اون پروداکته رو با جای اون عروس دریایی یه دقیقا جابجا کنی. همون شکلی animate بشه و motionش همین شکلی باشه. فقط به جای عروس دریایی تغییر بکنه به این پالیشره که... آره. و بعد توی این سایت برات فرستادم پروداکتمونه و پالیشره همینجوری بچرخه با سرعت خیلی کم و عین این animation جای این قرار بگیره. چرخ دنده هاش فقط اون پالیشره سرش بچرخه.
